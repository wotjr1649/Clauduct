# v0.6.6 — 종료 상태 파일 저장 재시도, `gpt-5.5` 은퇴 안내

2026-10-03. v0.6.5 출하 뒤 점검에서 확인한 항목을 고쳤다([PR #244](https://github.com/wotjr1649/Clauduct/pull/244)).
지원 범위는 [COMPATIBILITY.md](COMPATIBILITY.md)의 v0.6.6 절을 따른다.

## 바뀐 것

- **종료 상태 파일**
  - v0.6.3부터 알려진 제한이었다. 세션이 끝나는 순간 다른 프로세스가 `status-<pid>.json`을 공유 삭제 없이 열고
    있으면, Windows가 교체를 거부했고(`Access is denied.`) 최종 기록이 표준 오류에만 남았다.
  - 이제 최종 기록은 25 ms 간격으로 최대 40회(약 1초) 다시 시도한다. 세션 중 checkpoint는 대기 루프를 막지 않도록
    재시도하지 않는다.
- **`gpt-5.5` 은퇴 안내**
  - 계정 목록의 공지(은퇴 2026-10-14T19:00Z, 후속 `gpt-6.1-sol`)에 따라 은퇴 표에 `gpt-5.5 → gpt-6.1-sol`을 더했다.
  - 나열되는 동안은 그대로 실행되고, 목록에서 빠지면 `MODEL_RETIRED`로 후속 모델을 안내한다. 대체 실행은 하지 않는다.
  - 은퇴 판정은 "은퇴 표에 있고 계정 목록에 없음"으로 통일했다(`Selection.Retires`). 나열 중인 모델을 받지 않는
    effort로 고르면 일반 거부다.
  - `MODEL_RETIRED` 문구가 "v0.3.4가 은퇴시켰다"로 고정돼 있던 것을 고쳤다.
- **문서**: `COMPATIBILITY.md` 첫머리의 낡은 "v0.6.4 실제 backend NOT_RUN" 문장을 고쳤다.
- **로컬 검사 명령**: 일반·race 모두 `-timeout=120m`으로 실행한다. 이번에 `internal/app`이 일반 653.9초, race 631.9초로
  둘 다 기본 10분을 넘었다.

## 검증

- **로컬**
  - gofmt·vet·build 통과. `go test -timeout=120m`과 `-race -timeout=120m`이 각 22개 패키지에서 통과했다.
    문서 인용 검사도 통과했다.
  - 상태 파일 경합은 실제 Windows 파일 핸들로 재현했다. 150 ms 잡힌 파일에서 고치기 전에는 실패했고 고친 뒤에는
    성공했다. 계속 잡혀 있으면 상한 안에 실패하며 기존 파일은 온전히 남는다.
  - 독립 리뷰 지적 1건(나열 중인 은퇴 이름의 effort 불일치를 은퇴로 분류)을 고쳤고, 재리뷰에서 결함은 없었다.
    회귀 테스트는 시작 설정, context journal, bridge 판정을 고정한다.
- **실제 backend(사용자 승인, 이 릴리스 바이트)**: 17개 시나리오 통과. 은퇴 표에 있지만 계정이 나열하는 `gpt-5.5`도
  정상 실행됐다.
  - v0.6.5 변경 4개: 위임 메뉴, 표시 모델 인자, 숨긴 모델 전체 ID, TUI `/context`(계수 실패 0)
  - v0.6.4 회귀 13개
- **설치**: PowerShell 7.6.6에서 다음을 모두 통과했다.
  - 새 설치
  - v0.6.5 설치 후 교체·되돌리기
  - 설치본 세션(7회, 실패 0)
  - 발행 후 검증
  - `install.ps1 -Tag`
  - v0.6.5의 `--update --yes`
  - `.old` 정리
  - 두 번째 `--update` 무변경
- **이 머신의 실제 설치본**: v0.6.5에서 `--update --yes`로 v0.6.6이 됐다. digest 일치, `.old` 정리, 설정 변경 없음.

## 알려진 제한

- 종료 상태 파일을 1초보다 오래 잡는 프로세스가 있으면 최종 기록은 전처럼 표준 오류에만 남는다.
- `gpt-5.5`가 목록에서 빠진 뒤의 안내는 합성 목록으로 확인했다. 실제 은퇴 시점의 계정 목록으로는 아직 확인하지 않았다.
- v0.6.5와 v0.6.4의 다른 알려진 제한은 그대로다([v0.6.5](RELEASE-v0.6.5.md#알려진-제한),
  [v0.6.4](RELEASE-v0.6.4.md#알려진-제한)).
